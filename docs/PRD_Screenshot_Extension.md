# PRD — SnapCrop: Screenshot Chrome Extension

**Version:** 1.0  
**Date:** 2026-05-16  
**Status:** Draft  

---

## 1. Overview

### 1.1 Problem Statement
Пользователям нужен быстрый способ захватить выделенную область экрана прямо в браузере, аннотировать её и сохранить в нужном формате — без лишних шагов и без внешних инструментов.

### 1.2 Product Vision
Простое и быстрое Chrome-расширение для захвата области экрана с минимальным набором инструментов аннотации и мгновенной загрузкой файла.

### 1.3 Target Audience
Все пользователи Chrome — от новичков до профессионалов. Публикация в Chrome Web Store, бесплатно.

---

## 2. Goals & Non-Goals

### Goals
- Захват выделенной области одним кликом или горячей клавишей
- Базовая аннотация (стрелка, маркер, текст)
- Сохранение в PNG или PDF
- Автоматическая загрузка файла в папку Downloads

### Non-Goals (вне скоупа v1.0)
- Захват всего экрана / полной страницы / конкретного элемента
- Размытие (blur) областей
- Копирование в буфер обмена
- Облачное хранилище (Google Drive, Dropbox и др.)
- Таймер задержки перед захватом
- Видео / GIF запись
- Платные функции / монетизация

## 4. Functional Requirements

### 4.1 Активация
- **FR-01** Расширение активируется кликом по иконке в панели браузера
- **FR-02** Расширение активируется горячей клавишей `Alt+Shift+S`
- **FR-03** При активации страница затемняется, курсор меняется на crosshair

### 4.2 Захват области
- **FR-04** Пользователь зажимает ЛКМ и тащит — формируется прямоугольник выделения
- **FR-05** Во время выделения отображаются размеры области (px)
- **FR-06** Можно переделать выделение до подтверждения (ESC для отмены)

### 4.3 Редактор аннотаций
- **FR-07** После захвата открывается встроенный редактор поверх страницы (или в отдельной вкладке)
- **FR-08** Инструмент **Стрелка** — рисует направленную стрелку, фиксированная толщина 3px, цвет из набора (Red / Yellow / Black / White)
- **FR-09** Инструмент **Маркер** — полупрозрачная заливка прямоугольником, цвет из фиксированного набора (Red / Yellow / Black / White)
- **FR-10** Инструмент **Текст** — кликнуть на область, ввести текст; фиксированный шрифт Arial Bold 16px, цвет из набора
- **FR-11** Кнопка **Отмена (Undo)** — отменить последнее действие
- **FR-12** Кнопка **Очистить** — убрать все аннотации

### 4.4 Сохранение
- **FR-13** В редакторе — выбор формата: **PNG** или **PDF** (radio button или toggle)
- **FR-14** Кнопка **Скачать** → файл автоматически загружается в папку Downloads
- **FR-15** Имя файла по умолчанию: `snapcrop_YYYY-MM-DD_NNN.png / .pdf` (NNN — трёхзначный счётчик сессии: 001, 002, …)
- **FR-16** PDF сохраняет скриншот как изображение на странице формата A4 или по размеру области

### 4.5 Отмена / Выход
- **FR-17** `ESC` во время выделения — отменяет захват, возвращает страницу в нормальное состояние
- **FR-18** Кнопка **Закрыть** в редакторе — закрывает редактор без сохранения
- **FR-19** При невозможности захвата (например, страница `chrome://`) — показывается красный toast "Screenshot failed, try again" на 3 секунды

## 5. Non-Functional Requirements

| Категория | Требование |
|-----------|-----------|
| Производительность | Захват и открытие редактора — менее 500 мс |
| Совместимость | Chrome 110+ |
| Безопасность | Расширение не передаёт данные на внешние серверы |
| Приватность | Никакой телеметрии, никаких cookies, никакого трекинга |
| Размер | Расширение < 2 MB |
| Локализация | v1.0 — только английский интерфейс |

## 6. UX Flow

```
[Пользователь] 
    → Alt+Shift+S / клик иконки
    → Страница затемняется + crosshair курсор
    → Выделяет область мышью
    → Открывается редактор с захваченной областью
    → (Опционально) Добавляет аннотации
    → Выбирает PNG или PDF
    → Нажимает "Скачать"
    → Файл уходит в Downloads
    → Редактор закрывается
```

## 7. Technical Stack (рекомендации)

| Компонент | Технология |
|-----------|-----------|
| Extension framework | Chrome Extension Manifest V3 |
| Захват экрана | `chrome.tabs.captureVisibleTab` API |
| Редактор | Canvas API (HTML5) |
| PDF генерация | `jsPDF` (lightweight библиотека) |
| UI | Vanilla JS + CSS (без фреймворков, для минимального веса) |
